TARGET: https://on.pfcorp.eu/

SCOPE: on.pfcorp.eu only. Authorized lab pentest. No credential brute-force. No DoS (rate ≤20 concurrent). No destructive deletes of third-party data.

STACK (known from prior recon):
- App: transfer.sh (DutchCoders) behind F5 BIG-IP ASM
- WAF block façade: HTTP/2 404 + French title "Erreur 404 - Oups." + content-length ≈3821 + fixed security headers (NOT a real missing path)
- GET / reaches APP (transfer.sh help text) even when status is 404
- PUT/POST/OPTIONS previously hit WAF deny page

CLASSIFY every response as BLOCK | APP | OTHER using title + content-length + body snippet (first 120 chars), never status alone.

PRIVACY / TOOLS:
- Prefer darkmoon_execute_command only. Use URL placeholders (URL_NNN). Do not invent hostnames.
- Keep commands short. No huge katana -ef lists. No hydra.
- ffuf: -t 10 -timeout 8; wordlists ≤500 entries or head -n 300 of seclists.
- nuclei: only curated tags/templates relevant to upload/http/misconfig; -c 5 -rl 20; no full default run if >5 min.

PROGRAM — full scan, then report. Do all phases.

### Phase 1 — Fingerprint & baseline
1. curl -skI TARGET and curl -sk TARGET (save title, CL, body class APP/BLOCK)
2. whatweb -a 3 TARGET
3. wafw00f TARGET
4. httpx TARGET --title --tech-detect --status-code --web-server --cdn --ip --http2 (correct httpx CLI for this toolbox)
5. TLS: curl -skv --http1.1 TARGET 2>&1 | head useful lines; note HTTP/1.1 vs HTTP/2 differences if any

### Phase 2 — HTTP method matrix (one request each)
For /, classify BLOCK/APP/OTHER:
OPTIONS, GET, HEAD, POST, PUT, DELETE, PATCH, TRACE, CONNECT
Also: GET with unusual verbs via curl -X.
Record Allow headers if any.

### Phase 3 — transfer.sh upload surface (core app)
Goal: find any request that returns a real share URL (not deny page).
Try sequentially, stop a variant when APP returns a URL:
A) curl -T f.txt TARGET/name.txt
B) curl -T f.txt TARGET/
C) curl --upload-file f.txt TARGET/name.txt
D) PUT with Content-Type: application/octet-stream
E) POST multipart -F file=@f.txt to TARGET/ and TARGET/upload
F) Vary path: /upload /files /raw /download /put /api /v1
Create f.txt with short unique marker "darkmoon-lab-<timestamp>".
If upload succeeds, fetch the returned URL and confirm content.

### Phase 4 — WAF differential map (controlled, no spam)
Baseline BLOCK fingerprint from Phase 1.
One probe each; classify:
- Benign query ?q=hello
- XSS ?q=<script>alert(1)</script>
- SQLi ?id=1' OR '1'='1
- Path traversal /../../etc/passwd
- Header injection: User-Agent with <script>
- Content-Type text/xml with tiny XXE-like body (single request)
- Large but safe path encoding %2e%2e%2f
Note which trigger BLOCK vs pass-through to APP.

### Phase 5 — Content discovery (benign)
